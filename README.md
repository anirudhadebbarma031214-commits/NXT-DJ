# NXT DJ Stage
Windows Electron DJ mixing and Indian stage equipment simulator.

## Windows build
Open **Actions > Build Windows EXE** and select **Run workflow**. After a successful build, download **NXT-DJ-Windows-EXE** from Artifacts.

Or on Windows with Node.js installed: `npm install`, then `npm start` (development) or `npm run dist` (EXE).

**Note:** Generator, Sharpy, amplifiers, and DMX panels are simulated only; they do not operate physical equipment. No real electrical power control. Test audio hardware independently before live use.
